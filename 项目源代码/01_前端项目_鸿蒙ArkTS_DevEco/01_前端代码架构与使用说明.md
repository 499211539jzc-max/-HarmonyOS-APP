# 鸿蒙前端工程说明文档（HarmonyOS / ArkTS）

本工程基于华为 DevEco Studio 构建，采用声明式开发范式（ArkTS），实现了《云栖酒店》智慧客房与公共设施的交互控制、传感器数据实时呈现与用户认证。

---

## 📂 核心代码目录与文件说明

| 相对路径 | 对应角色 | 核心功能与技术实现 |
| :--- | :--- | :--- |
| **`entry/src/main/ets/pages/RoomControl.ets`** | 客房控制页面 | **客房核心控制面板**：<br>1. **灯光控制**：总开关、筒灯、灯带、床头灯开关（下发 `light_on`/`light_off` 控制板载 LED）；<br>2. **空调与风机**：温度调节（▲/▼）及 4 种模式点击（下发 `motor_on`/`motor_off` 启停排风电机），中央动态显示硬件 SHT30 实时上报温度；<br>3. **窗帘与蜂鸣器**：打开/暂停/关闭按钮联动下发 `beep_on`/`beep_off` 控制板载蜂鸣器鸣响；<br>4. **防循环与遥测**：内置 `isSyncingUi` 状态锁防止父子开关递归触发，3秒定时器拉取最新遥测数据与烟雾报警检测。 |
| **`entry/src/main/ets/pages/PublicFacility.ets`** | 公共设施页面 | **公共服务与门禁联动**：<br>1. **洗衣房**：设备状态展示，点击底部的「📅 立即预约空闲设备」确认后联动触发闸道开门；<br>2. **智能电梯**：电梯楼层与运行监控，点击「🔔 呼叫电梯」弹窗确认后联动门禁开闸。 |
| **`entry/src/main/ets/common/DeviceService.ets`** | 统一网络通信层 | **全平台自适应通信中枢**：<br>1. **多网段自动探测容灾**：依次探测本地模拟器 (`10.0.2.2:3000`)、DevEco 预览器 (`127.0.0.1:3000`) 与真机局域网 (`10.84.189.134:3000`)，无需手动修改 IP；<br>2. **前端 350ms 防抖节流**：过滤用户手滑高频连点，保护下位机单片机串口不被冲垮；<br>3. 封装 `control(cmd)` 与 `getStatus(callback)` 两个核心方法。 |
| **`entry/src/main/ets/pages/Index.ets`** | 登录认证页面 | **用户体系**：支持手机短信验证码登录、账号密码登录与新用户注册，集成倒计时防刷。 |
| **`entry/src/main/ets/pages/Second.ets`** | 业务主页仪表盘 | **客房首页**：展示客人入住信息卡片（如 8012 房），提供进入客房控制、公共设施、客房服务与个人中心的九宫格入口。 |
| **`entry/src/main/module.json5`** | 模块权限声明 | 声明了 `ohos.permission.INTERNET` 网络访问权限。 |

---

## 🛠️ 开发与调试运行说明

1. 使用 **DevEco Studio** 打开当前文件夹（`01_前端项目_鸿蒙ArkTS_DevEco`）；
2. 依赖将通过 ohpm 自动加载（或执行 `ohpm install`）；
3. 支持三种运行环境：
   - **右侧 Previewer 实时预览**：访问电脑 `127.0.0.1:3000`；
   - **本地模拟器 (Emulator)**：通过网关访问宿主机 `10.0.2.2:3000`；
   - **鸿蒙真机 USB/无线调试**：手机与电脑处于同一局域网 Wi-Fi 下访问 `10.84.189.134:3000`。
   *(网络层内部已实现三地址无缝回退，开箱即用)*
