# 嵌入式底层固件说明文档（STM32L431 + ESP8266）

本工程基于 Keil MDK-ARM (uVision5) 与 STM32 HAL 库开发，烧录于智慧客房单片机底板（主控为 STM32L431RCT6），并挂接了 ESP-12F / ESP8285 Wi-Fi 扩展板，负责执行物理动作与传感器数据采集。

---

## 📂 核心代码目录与驱动说明

| 相对路径 | 对应驱动模块 | 核心功能与技术实现 |
| :--- | :--- | :--- |
| **`Src/main.c`** | 单片机主程序 | **系统主调度中心**：<br>1. 系统时钟、GPIO、定时器 PWM、ADC 与多串口初始化；<br>2. 开机硬件自检动作（灯闪、电机转动、蜂鸣器轻鸣、舵机归位）；<br>3. 初始化 Wi-Fi 连接（热点 `GZ` / 密码 `20051007jzc`）与 MQTT 认证连接；<br>4. 主循环：每 2 秒读取 SHT30 温湿度并通过 JSON 上报至 `sensorData`；监测 MQ-5 烟雾与 PIR 人体红外；响应非阻塞动作标志。 |
| **`Utils/esp8285.c`** | Wi-Fi 模组 AT 驱动 | **AT 指令状态机与通信保护**：<br>1. 与 ESP8266 模组进行 UART1 全双工交互；<br>2. 修复 STM32 HAL 串口锁（`huart1.Lock`）冲突问题；<br>3. 实现了防溢出安全环形缓冲机制，避免高频指令打垮单片机；<br>4. 在中断接收中捕获 `+MQTTDISCONNECTED` 状态，触发主循环 3 秒自动重连；<br>5. 收到 `commandtopic` 下发的控制指令后，立即调用各外设原子动作函数。 |
| **`Utils/mqtt.c`** | MQTT 协议栈封装 | **MQTT 客户端实现**：<br>1. `MQTT_Connect`：通过 AT 指令配置客户端属性并连接 EMQX Broker；<br>2. `MQTT_Publish`：封装 `AT+MQTTPUBRAW` 报文发送，支持根据返回值触发断线计数重连；<br>3. `MQTT_Subscribe`：订阅控制主题 `commandtopic`。 |
| **`Src/tim.c`** | 定时器与 PWM 驱动 | **舵机道闸与风机控制**：<br>1. `TIM1_CH4` 与 `TIM2_CH1` 输出高精度 50Hz PWM 脉冲，驱动左右两个舵机动作；<br>2. `Gate_Open()`：左舵机顺时针 90°，右舵机逆时针 90° 开闸；<br>3. `Gate_Close()`：左右舵机复位至 150 平放闭合原位。 |
| **`Src/gpio.c`** | GPIO 逻辑驱动 | 控制高亮 LED 主灯（PB15 / PA4）、排风扇电机（PA8）、蜂鸣器（PE8）、板载按键扫描及在线指示灯（PA6）。 |
| **`MDK-ARM/`** | Keil 工程与固件目录 | 包含 `samrtHome.uvprojx` 工程文件，以及编译完成的 `samrtHome.hex` 与 `samrtHome.axf` 固件产物。 |

## 🔌 硬件引脚与外设定义

| 外设名称 | 芯片引脚 | 功能类型 | 控制逻辑说明 |
| :--- | :--- | :--- | :--- |
| **高亮主灯 (Light)** | PB15 / PA4 | GPIO 输出 | 低电平亮 / 高电平灭，响应 `light_on` / `light_off` |
| **排风电机 (Motor)** | PA8 | GPIO 输出 | 高电平旋转 / 低电平停止，响应 `motor_on` / `motor_off` |
| **门禁舵机 1 (左)** | TIM1_CH4 | PWM (50Hz) | 脉宽 100~150，逆时针/顺时针 90° 旋转 |
| **门禁舵机 2 (右)** | TIM2_CH1 | PWM (50Hz) | 脉宽 150~200，顺时针/逆时针 90° 旋转 |
| **报警蜂鸣器 (Beep)**| PE8 | GPIO 输出 | 蜂鸣鸣响，响应 `beep_on` / `beep_off` |
| **烟雾传感器 (MQ-5)** | PD15 | GPIO 输入 / ADC | 检测可燃气体泄漏，低电平为检测到超标气体触发报警 |
| **人体红外 (PIR)**   | PC8 | GPIO 输入 | 检测到有人移动时输出高电平 |
| **Wi-Fi 通讯串口**    | USART1 (TX/RX) | 115200 8-N-1 | 与板载 ESP-12F / ESP8285 扩展板通信 |
| **调试输出串口**      | USART2 (TX/RX) | 115200 8-N-1 | 向上位机打印系统运行日志与调试信息 |

## 🛠️ 编译与烧录方法

1. 使用 **Keil uVision5 (MDK-ARM)** 打开 `MDK-ARM/samrtHome.uvprojx`；
2. 点击顶部菜单的 **Rebuild All Target Files**（快捷键 F7）进行编译；
3. 将板子通过 Type-C 数据线连接电脑的 **STLINK DEBUG** 端口；
4. 点击 Keil 顶部的 **Download** 按钮（快捷键 F8）即可将最新固件写入单片机 Flash。
