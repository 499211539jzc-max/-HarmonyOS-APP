# 后端中台与网关服务说明文档（Node.js / Express / MQTT）

本工程基于 Node.js + Express 搭建，作为整个系统的枢纽，向上为鸿蒙移动端提供标准 RESTful HTTP 接口，向下通过 MQTT 协议与 EMQX Broker 和 STM32 硬件进行低延迟双向通信。

---

## 📂 核心代码文件说明

| 文件名 | 对应角色 | 核心功能与技术实现 |
| :--- | :--- | :--- |
| **`server.js`** | 服务主程序与协议网关 | **核心业务与通讯中枢**：<br>1. **MQTT 客户端桥接**：启动自动连入 EMQX Broker（`192.168.10.111:1883`），断网 3 秒自动重连；<br>2. **遥测数据解析**：订阅 `sensorData`，将硬件上报的温湿度、燃气、人体红外等状态实时缓存在内存 `deviceState` 中；<br>3. **设备控制路由**：实现 `POST /api/device/control`，将前端控制动作映射为原子指令推送到 `commandtopic`；<br>4. **服务端 250ms 防抖限流**：阻断短时间内的重复多余指令；<br>5. **闸道异步时序调度**：针对开闸动作，先发送 `gate_open`，并在 2.5 秒后自动发送 `gate_close` 恢复原位，开门期间自动过滤连点请求；<br>6. **短信与认证接口**：实现 `/api/sms/send`、`/api/auth/login-code`、`/api/auth/register` 等。 |
| **`db.js`** | 数据库与存储引擎 | **数据持久化与容灾**：<br>1. 基于 `mysql2/promise` 维护数据库连接池；<br>2. 自动检查并初始化 `users` 与 `sms_codes` 表；<br>3. **高可用降级备份**：若本地未安装 MySQL 或数据库连接失败，系统自动无缝降级为内存存储引擎（`memoryStore`），绝不阻碍系统运行。 |
| **`package.json`** | 依赖配置清单 | 引入了 `express`、`mqtt`、`mysql2`、`axios`、`cors`、`dotenv` 等核心依赖包。 |
| **`start_server.bat`** | Windows 一键启动脚本 | 切换至当前目录，直接运行 `node server.js`，方便开箱启动。 |
| **`.env`** | 环境变量配置文件 | 存储后端运行端口（默认 3000）、数据库配置与阿里云短信 AppCode。 |

## 🛠️ 接口清单与协议规格

### 1. 设备状态接口
- **请求方式**：`GET /api/device/status`
- **返回示例**：
  ```json
  {
    "code": 200,
    "message": "获取设备状态成功",
    "data": {
      "temp": 24.5,
      "humi": 50.2,
      "gas": 1,
      "human": 0,
      "light": 1,
      "motor": 0,
      "gate": 0,
      "beep": 0,
      "mqttOnline": true
    }
  }
  ```

### 2. 设备控制接口
- **请求方式**：`POST /api/device/control`
- **请求体格式**：
  - 直接指令：`{ "command": "light_on" }`
  - 或语义化：`{ "device_type": "light", "power": 1 }`
- **支持的核心指令**：
  - 灯光：`light_on` / `light_off`
  - 风机：`motor_on` / `motor_off`
  - 蜂鸣器：`beep_on` / `beep_off`
  - 闸道：`gate_test`（开闸并在2.5秒后自动关闸回原位）/ `gate_open` / `gate_close`

## 🚀 启动与调试方法

1. 确保电脑已安装 Node.js（推荐 v16+ / v20+）；
2. 首次在此目录下打开终端执行：
   ```bash
   npm install
   ```
3. 双击 `start_server.bat` 或在终端运行：
   ```bash
   npm start
   ```
4. 出现 `云栖酒店后端服务已启动: http://localhost:3000` 即表示服务正常就绪。
